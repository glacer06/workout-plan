PAIR FITNESS - ICON SET

(The app is Pair Fitness since Nov 8, 2026, Pair Strong for two days before that. The sims-fitness file names below
were kept so nothing breaks.)

Current mark (Nov 12, 2026, branch mark-kettlebell-p): the gunmetal kettlebell with a woven P embossed where the S was.
Gold is the default Colors pick, blue is the electric blue palette. File names were kept.
  sims-fitness-gunmetal.png              1024 x 1024 gold icon, opaque. Also the iPhone and Apple Watch app icon source.
  sims-fitness-gunmetal-180.png          180 x 180 home screen icon.
  icon-nick-16/32/180/192/512.png        Gold home screen and web app icons (the 16 and 32 are for tab favicons).
  icon-steph-16/32/180/192/512.png       The same mark on the blue palette.
  apple-touch-icon(.precomposed).png     180 x 180, same as icon-nick-180.
  sims-fitness-icon.mobileconfig         Web Clip for Nick's phone, 400 x 400 gold icon built in.
  sims-fitness-gold-transparent.svg/.png 1024 transparent cutout of the gold icon (the in-app header logo, loading splash
                                         mask and Colors chip). No ground shadow, handle opening clear.
  steph-fitness-B-transparent.svg/.png   The same cutout of the blue icon (names kept from the B set below).
The web app uses the SVGs. Each SVG carries the cutout itself (a 512 px JPEG for color plus a grayscale mask for the shape,
about 60 to 75 KB), not a flat vector redraw, so the header and splash match the app icon. The PNGs are the full 1024
cutouts; the iPhone's BrandLogoPaletteA/B are half-size copies of them. Each sits where its old S file did, so the gold
kettlebell fills about 80% of the frame's height and the blue one about 88%, as before.
favicon.svg is still the blue B. Nothing links it (tab icons are icon-nick/steph-16 and 32), so it was left alone.
Before the P (Oct 17): a dark kettlebell with an old gold S on a gunmetal grey gradient; it is in git history.
The old dark grey (#2B2B2B) icon and its favicon were deleted on Oct 27, 2026. Use the gunmetal files.
The blue files below are the original approved set, kept for reference and rollback.

ORIGINAL B ICON SET (blue)

The final mark is candidate B: dark navy faceted kettlebell with a bold white S.
(The app was renamed from Steph Fitness to Sims Fitness on Sept 26, 2026. File names below were kept so nothing breaks.)

Files:
  steph-fitness-B-blue.png          Exact approved 1024 x 1024 electric-blue raster master, unchanged.
  steph-fitness-B-white.png         1024 x 1024 PNG with a white background and soft ground shadow.
  steph-fitness-B-transparent.png   (Now the blue P cutout above; the B cutout is in git history.)
  steph-fitness-B-blue.svg          Hand-built, editable vector adaptation on electric blue.
  steph-fitness-B-white.svg         Same vector mark on white with ground shadow.
  steph-fitness-B-transparent.svg   (Now the blue P cutout above; the B vector is in git history.)
  favicon.svg                       Tighter crop of the blue mark for browser tabs.

The SVGs are deliberate flat vector redraws of B's silhouette, facets and white S, not pixel-for-pixel 3D copies of the raster renders. The white and transparent PNGs are cut-out adaptations of B; their contours may look slightly softer than the original blue master. For the exact approved image, use steph-fitness-B-blue.png.
